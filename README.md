# ab-test-analysis

A/B testing analysis using Python, SQL, and statistical hypothesis testing

\# A/B Test Analysis



\## Project Overview

This project analyzes an A/B experiment to compare a control group with a treatment group and evaluate whether a change improves a key business metric.



\## Objectives

\- Inspect and clean the dataset.

\- Check missing values, duplicates, and data quality.

\- Calculate conversion rates for both groups.

\- Test statistical significance.

\- Communicate findings through visualizations and a final report.



\## Tools

\- Python

\- Pandas and NumPy

\- SciPy and Statsmodels

\- Matplotlib and Seaborn

\- SQL

\- Git and GitHub



\## Project Structure

\- `data/` — Dataset files

\- `notebooks/` — Python analysis notebooks

\- `sql/` — SQL queries

\- `requirements.txt` — Python dependencies
